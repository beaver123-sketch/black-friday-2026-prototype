# Black Friday 2026 — POPPO Live Activity Prototype

Mobile high-fidelity interactive HTML prototype with two tabs:
- Promotion (SVIP benefits and 18 Rare IDs)
- Top-up Ranking (7-day ranking, rewards and rules)

## GitHub Pages deployment

1. Create a public GitHub repository named `black-friday-2026-prototype`.
2. Add `index.html` and `.nojekyll` to the `main` branch at the repository root.
3. In the repository, open **Settings → Pages**.
4. Under **Build and deployment**, select **Deploy from a branch**, choose **main** and **/(root)**, then save.
5. The URL will be `https://<username>.github.io/black-friday-2026-prototype/` after Pages reports a successful deployment.

## Notes

- Names and totals shown in the leaderboard are sample data, not real results.
- Some Rare IDs are greyed out as demonstration states only.
- Share, SVIP and Mall CTA interactions are prototype simulations, not live app deep links.
- Changes to `index.html` published to `main` will be reflected after GitHub Pages rebuilds.
